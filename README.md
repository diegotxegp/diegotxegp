# Hi, I'm Diego García-Prieto 👋

Computer scientist and PhD candidate at the **University of Cantabria**, researching **Human-Guided Machine Learning** and **Human-Centered AI**.

I'm interested in making machine learning understandable and usable for people without programming or AI expertise, especially in clinical research. My work combines AutoML, human-computer interaction and data science, and I like building tools as much as writing about them. Before this, I worked on distributed real-time systems and on security and machine learning applied to malware analysis.

## 🔭 Currently

- Working on my PhD thesis, built around **[Hamelin](https://github.com/diegotxegp/hamelin)**, a no-code, protocol-aware AutoML application for clinical research.
- Writing papers and giving talks about human-guided machine learning.

## 🌱 Interests

AutoML · Human-Centered AI · Human-Computer Interaction · Data Science · Clinical ML · Real-time Systems · Cryptography & Cybersecurity
